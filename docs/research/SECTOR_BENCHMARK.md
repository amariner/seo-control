## Product thesis

Competitive advantage is not the number of dashboards. SEO Intelligence must
close, and preserve evidence across, this loop:

> Detect -> Explain -> Prioritise -> Decide -> Execute -> Measure -> Learn

That loop is the product architecture. A graph, table, alert, report or editorial
item is valuable only when it advances a decision through it.

## Differentiation layers

1. **V1 parity and operational continuity**: nothing is retired until equivalence
   is verified, starting with the group editorial calendar.
2. **Decision operating system**: one queue for signals, insights, risks and
   opportunities with evidence, confidence, impact, effort, owner, deadline,
   success criterion and state.
3. **Explainable exploration**: entity pages, diffs, relationships, contribution
   trees and contextual navigation without losing filters.
4. **Monitoring and prevention**: persistent alerts, change history, release
   annotations and technical/accessibility quality gates.
5. **Content, demand and GEO**: connect clusters, gaps, decay, cannibalisation,
   citations and assistants to published work and measured outcomes.
6. **Impact and experimentation**: intervals, baselines, before/after, controls
   when feasible and reusable learning.
7. **Controlled automation**: briefs and tickets first; reversible changes with
   approval, audit and rollback only after the evidence loop is mature.

## Editorial calendar as the operating spine

The calendar is not a detached planner. Every editorial item must connect:

> insight/opportunity -> proposal -> brief -> asset/cluster -> project/market ->
> owner/review -> publication -> 28/90/180-day windows -> measured result -> learning

Minimum fields are project, market, language, cluster/pillar, intent, page type,
target URL, primary/secondary queries, objective, hypothesis, expected impact,
effort, owner, author, reviewer, dependencies, state, planned/actual dates,
evidence, baseline, success KPIs and outcome.

This connection between planning, insight, action and outcome is the primary
differentiation opportunity: the product should make a publication's rationale
and result inspectable from the same thread.
